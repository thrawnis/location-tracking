Getting a precise location

Precise location comes from your phone's GPS and needs the browser's permission:

  • Tap Locate (the ◎ button), then Allow when prompted.
  • iPhone: Settings → Privacy & Security → Location Services → On, and set your browser to While Using.
  • Brave: tap the shield/lock icon in the address bar → Site settings → Location → Allow, then reload. Brave blocks location by default. If it still fails in Brave, try Safari.
  • On a computer there's no GPS, so location is only city-level — that's a hardware limit, not a bug.
  • Any time it can't get a precise fix, just type your city, state, or zip in the box.
